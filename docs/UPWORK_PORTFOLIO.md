# Upwork Portfolio Copy

## Title

AI WhatsApp Support & Booking Assistant — FastAPI, n8n

## Role

AI Automation Developer

## Description

I built a safe, mock-first AI customer support and appointment booking assistant for a fictional service business. The system validates WhatsApp-style webhooks, classifies customer intent, answers FAQs only from an approved knowledge base, checks availability in Europe/Warsaw, requires explicit confirmation, prevents double booking, synchronizes confirmed records to a mock Google Sheet and hands complex requests to a manager.

Python/FastAPI owns validation, booking state and idempotency; n8n only orchestrates approved API calls. The project includes SQLite audit history, prompt-injection protection, replay-safe recovery and 100 automated tests covering all three demo services, integration failures, DST, end-to-end booking and publication assets.

This is an independent fictional portfolio demonstration using synthetic data. It is not a commercial client project, and real Meta, Gemini or Google APIs were not connected.
